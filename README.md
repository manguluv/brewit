# ☕ BrewIt!

커피 레시피 관리 & 브루잉 타이머 웹앱

핸드드립 커피를 내릴 때 레시피를 확인하고, 타이머와 함께 정해진 시간에 정해진 양의 물을 부을 수 있도록 도와주는 심플한 도구입니다.

## ✨ 기능

### 레시피 목록
- 6개 기본 레시피 내장 (4:6 메서드, 클래식 V60, 호프만 V60, 오리카미 라이트, 다크 로스트, 간편 3단계)
- 커스텀 레시피 추가 및 삭제 (localStorage 저장)

### 레시피 상세
- 원두량·물 총량·비율·수온·분쇰도·로스트 정보
- **원두량 스케일링**: 원두량을 변경하면 모든 투입량이 비례 자동 계산
- 단계별 추출 표 (시간 · 단계명 · 투입량 · 누적량)

### BrewIt! 타이머
- 카운트업 타이머
- 현재 부어야 할 물의 양을 큰 숫자로 표시 (예: `70g`)
- 누적/총량 진행률 바 (예: `120g / 300g · 40%`)
- 단계 자동 하이라이트 + 진동 알림
- 화면 꺼짐 방지 (Wake Lock API)
- 완료 시 진동 + 완료 메시지

## 🚀 실행

정적 파일 3개(`index.html`, `style.css`, `app.js`)로 구성되어 있어 별도 빌드 없이 브라우저에서 바로 열면 됩니다.

```bash
# 로컬 서버
python3 -m http.server 8765
# 브라우저에서 http://localhost:8765 접속
```

또는 `index.html`을 더블클릭해도 됩니다.

## 🛠 기술 스택

- Vanilla JS (프레임워크 없음)
- CSS 변수 기반 다크 테마
- localStorage (커스텀 레시피 저장)
- Wake Lock API (화면 꺼짐 방지)
- Vibration API (단계별 알림)
